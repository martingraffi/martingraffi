# 💫 Sobre mi:

🔭 **Actualmente estoy trabajando en:** El desarrollo de automatizaciones y bots en Python (como un monitor de mercado de valores con la API de Invertir Online) y la creación de un dashboard de inversiones automatizado que integra Notion y Telegram. Recientemente **concluí mi Tesis**, desarrollando SIGCET y la app para "Los Gallegos", enfocados en la gestión de stock y auditorías con arquitectura modular. Además, estoy construyendo un gestor de contraseñas local para profundizar en el manejo de archivos y hashing.

👯 **Busco colaborar en:** Automatización, Ciberseguridad, Web Scraping, gestión de infraestructura local (Homelab), scripts en Bash/Python para servidores y despliegue de soluciones Open Source.

🌱 **Actualmente estoy aprendiendo:** Cursando la Licenciatura en Ciberseguridad en la UGR, estudiando System Design para arquitecturas escalables, y profundizando en Python para aplicarlo en automatizaciones, IA y Machine Learning.

💬 **Pregúntame sobre:** Cómo montar un Homelab económico y eficiente. Me encanta transformar hardware en desuso (notebooks, Raspberry Pi 5) en servidores de producción administrando contenedores con Docker y Portainer, configurando túneles, y gestionando todo vía terminal y OpenSSH.

⚡ **Un dato curioso:** Mi centro de datos híbrido incluye una Raspberry Pi 5 para servicios web y una notebook HP Pavilion reutilizada con Windows 11 como media server. ¡Este último gestiona de forma automática **2TB (dos discos de 1TB)** de contenido multimedia (con Jellyfin, los *arrs* y qBittorrent) sin intervención manual!
